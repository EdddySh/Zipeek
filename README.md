**Zipeek** brings the fast preview experience of Arc and Zen Browser (Glance) to your everyday browser.
Inspect any link instantly in an interactive, highly customizable floating window: choose from multiple visual themes (glassmorphism, minimalist styles, and Hyprland Colored), tweak window dimensions, and control scroll speed. Ultralight, built on Manifest V3, and completely private with zero data collection.

### What Zipeek offers

- ⚡ **Glance / Arc-like experience:** Hover over a link or press your shortcut to load the actual page in an overlay floating window. Read, interact, and close it with an outside click or by pressing `Esc`.
- 🎨 **Adaptive themes & design:** Pick from several visual styles (including translucent glassmorphic effects or clean designs), complete with smooth borders and automatic light/dark mode switching.
- ⚙️ **Customization:** Adjust frame dimensions, screen position, and scroll speed to match how you browse.
- 🔋 **Lightweight (Manifest V3):** Zero memory hogging, no page-load slowdowns.
- 🛡️ **100% Private:** Open-source, no telemetry, no trackers, and no browsing history stored. What you view stays strictly on your machine.

### Manual installation (Developer mode)

If you want to try the latest changes early or run it on Chromium while the store approval finishes:

1. Download and extract the `.zip` archive from [Releases](https://github.com/EdddySh/Zipeek/releases).
2. **On Chrome / Brave / Edge:** Go to `chrome://extensions/`, enable **Developer mode** in the top right, and click **Load unpacked**.
